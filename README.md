# Introduction to Python for ONS Colleagues

These training materials were originally created to introduce ONS colleagues to the basics of data manipulation in Python. No prior Python or coding experience is assumed.

The content was last reviewed in **June 2025**.

---

# How to Use These Resources

This course is designed to be delivered over six two‑hour sessions, typically run across six weeks. It is intended to be **instructor-led**, rather than a self‑study resource. The approach is for the instructor to write and run code live, with learners replicating the steps, asking questions, and working through error messages together. Understanding and interpreting error messages is a key skill taught throughout the course.

By the end of the training, learners should feel confident enough to begin any introductory Python course on the Learning Hub, YouTube, or from a book. While there are many excellent Python tutorials available online, this resource is tailored specifically for learners who benefit from guided, confidence‑building support at the very start of their Python journey.

**Presentations used for each session aren't included yet but these will be included shortly.**

# Weekly Breakdown

### **Week 1: Introduction to Programming and Simple Data Exploration**
- What programming and coding are.
- Opening *2011.csv* (the [2011 Census Teaching File](https://www.ons.gov.uk/census/2011census/2011censusdata/censusmicrodata/microdatateachingfile)).
- Producing simple descriptive statistics.

### **Week 2: Core Python Concepts and Working with DataFrames**
- Basic Python data types.
- How to use a Jupyter Notebook (comments, markdown, running cells).
- Basic logic and inequalities.
- Re‑importing the Week 1 dataset (intentional repetition).
- Creating a new DataFrame of widowed individuals and exporting it to a CSV file.

### **Week 3: Intermediate Data Manipulation**
- Introduction to dictionaries.
- Applying functions to columns.
- Creating new columns by combining existing ones.

### **Week 4: Aggregation and Simple Visualisation**
- Creating aggregate tables.
- Making basic plots for exploratory data analysis.
- How to use LLMs such as Microsoft Copilot to help write Python code.

### **Week 5: Applying Skills to a New Dataset**
- Bringing together all skills from previous weeks.
- Working with a new dataset (either a general election dataset or Olympics data).
- Conducting a simple data‑profiling exercise.

### **Week 6: Introduction to Git and GitHub**
- Learning basic Git commands.
- Understanding version control.
- Saving and sharing work via GitHub.
